Fast Inference from Transformers via Speculative Decoding

Yaniv Leviathan, Matan Kalman, Yossi Matias

Google Research, 2022 | arXiv:2211.17192

Abstract

Inference from large autoregressive models like Transformers is slow - decoding K tokens takes K serial runs of the model. This work introduces speculative decoding, an algorithm to sample from autoregressive models faster without any changes to the outputs, by computing several tokens in parallel.

Key Insight

The core observations are:

  • Hard language-modeling tasks often include easier subtasks that can be approximated well by more efficient models
  • Using speculative execution and a novel sampling method, exact decoding from large models can be made faster by running them in parallel on outputs of approximation models

How It Works

Step 1: Draft Generation
A smaller, faster "draft" model generates K candidate tokens autoregressively. This is cheap because the draft model is much smaller.

Step 2: Parallel Verification
The large "target" model processes all K draft tokens in a single forward pass (in parallel), computing the probability distribution at each position.

Step 3: Acceptance/Rejection
For each draft token, compare the draft model's probability with the target model's probability:

  • If target probability >= draft probability: Accept the token
  • Otherwise: Accept with probability (target_prob / draft_prob), reject otherwise

Step 4: Recovery
When a token is rejected, sample a new token from an adjusted distribution. This ensures the final output distribution is identical to sampling directly from the target model.

Mathematical Guarantee

The key theorem proves that speculative decoding produces samples from the exact same distribution as standard autoregressive sampling from the target model. The acceptance probability is designed so that:

P(accept) = min(1, p_target(x) / p_draft(x))

When rejection occurs, the residual distribution is sampled to maintain correctness.

Results

  • 2X-3X acceleration on T5-XXL compared to standard T5X implementation
  • Identical outputs to the original model (not an approximation)
  • No retraining or architecture changes required
  • Works with existing off-the-shelf models

Why It Matters

Speculative decoding addresses the fundamental bottleneck of autoregressive generation: memory bandwidth. Large models are often memory-bound, not compute-bound. By generating multiple tokens per forward pass of the large model, speculative decoding better utilizes available compute while maintaining exact correctness.

Practical Considerations

  • Draft Model Selection: The draft model should be fast while having reasonable agreement with the target model
  • Speculation Length (K): More speculation = more potential speedup, but also more wasted computation on rejection
  • Best for: Tasks where draft model can predict target model well (e.g., code completion, structured outputs)
